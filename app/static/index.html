我发了一句话

Given 我在飞书群 / 私聊里 @ AgentMate 发消息
  • • 收到即回执：「✅ 已接收，正在处理…」；任务拥挤时告知「正在排队处理…」
  • • 连续多条消息自动合并，不会重复处理
  • • 多轮对话带上下文，追问「那第二个呢」也听得懂

系统怎么处理

When 消息进入编排闭环（router → agent → gather）
  • • RouterLLM 判断这句话交给谁：直接回答 / 专业助手 / 反问澄清
  • • 交给专业助手时先看到「正在交给 XX 处理…」
  • • 回复经过质量判定，不满足意图自动换路重试

我看到了什么

Then [用户看到] 可观察的终态，绝不静默
  • • 正式回复 / 追问澄清 / 诚实告知做不到，三选一必达
  • • 排队超时或拥挤时明确说「系统繁忙，请稍后再试」
  • • 服务重启中断的任务，重启后主动提醒重新发送
